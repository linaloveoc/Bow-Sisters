# BowSister website

## Preview
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a public GitHub repository, such as `bowsister`.
2. Upload all files and folders from this package without changing their structure.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, then `/ (root)`, and save.
5. GitHub provides the live link after it publishes.

## Before sharing publicly
- Confirm artist permissions and add exact credits/links for commissioned, gifted, or collaborative art.
- Replace or remove any image you do not have permission to display.
- Review content ratings and decide which images should be public, blurred, or private.
- Add your social links/contact information in the About section if desired.

## Add an image
1. Copy the image into `assets/images/`.
2. Add an `<figure>` in `index.html` within the appropriate gallery.
3. Give every image descriptive alt text and a credit caption.
